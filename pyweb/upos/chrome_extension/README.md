# U-POS Телефон для Chrome

Виджет регистрирует SIP-линию в скрытом документе расширения. Вкладку U-POS можно закрыть: входящие уведомления и разговор продолжают работать, пока Chrome открыт и линия зарегистрирована. После перезапуска Chrome войдите в виджет заново.

Для установки откройте `chrome://extensions`, включите режим разработчика, выберите «Загрузить распакованное расширение» и укажите эту папку. Нажмите значок расширения и введите аккаунт организации, логин и пароль SIP-линии. Разрешите доступ к микрофону. У линии должен быть рабочий `wss://` адрес и действительный сертификат.

При входящем вызове расширение воспроизводит сигнал, показывает уведомление и открывает окно с анимацией и кнопками «Принять» и «Отклонить». Виджет также позволяет звонить и переадресовывать входящие до ответа, если АТС поддерживает SIP 302. Выделенный на любой странице номер можно набрать через контекстное меню. Записи разговоров отправляются в U-POS и далее в настроенную Telegram-группу.

SIP-пароль и токен интеграции хранятся в `chrome.storage.session`, который очищается при закрытии Chrome. Устройство должно оставаться включённым, Chrome — открытым, а соединение с АТС — доступным. Входящий публичный номер, IVR и очереди настраиваются на АТС или через SIP-транк; расширение само не меняет маршрут оператора связи.
