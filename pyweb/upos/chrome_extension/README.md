# Звонок из Chrome через U-POS

Расширение добавляет действие «Позвонить через U-POS» для выделенного номера на любой странице. Оно открывает существующую вкладку U-POS и подставляет номер в плавающий телефон. Звонок начинается только после нажатия кнопки оператором.

Для локальной установки откройте `chrome://extensions`, включите режим разработчика, выберите «Загрузить распакованное расширение» и укажите эту папку. Войдите в U-POS в Chrome и разрешите микрофон для `https://app.u-pos.uz`.

Расширение не хранит пароль SIP. Внутреннюю линию администратор назначает сотруднику в разделе «Телефония → Интеграции». Для звонков из браузера у АТС должен работать защищённый адрес `wss://` с действительным сертификатом для домена.
