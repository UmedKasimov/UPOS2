# U-POS Телефон для Chrome 0.5.0

Расширение держит SIP-линию в скрытом документе Chrome. После подключения со статусом «На линии» вкладку U-POS можно закрыть. Плавающий телефон появляется поверх обычных вкладок Chrome; кнопку можно перетащить по экрану. Входящий вызов раскрывает панель с кнопками «Принять», «Отклонить» и переадресацией. Разговор и запись продолжаются при смене вкладки.

## Установка и обновление

1. Скачайте свежий архив `https://app.u-pos.uz/telephony/chrome-extension.zip` и распакуйте его в постоянную папку. Не выбирайте сам ZIP в Chrome.
2. Откройте `chrome://extensions`, включите «Режим разработчика». Для первой установки нажмите «Загрузить распакованное расширение» и выберите распакованную папку. Для обновления замените файлы в той же папке и нажмите «Обновить» на карточке расширения.
3. После обновления подтвердите Chrome разрешение показывать телефон на сайтах. Откройте U-POS и войдите в аккаунт. Нажмите значок «U-POS Телефон» в Chrome, затем «Открыть окно подключения». В отдельном окне нажмите «Подключить из открытой U-POS» и разрешите микрофон. Если запрос не появился, проверьте `chrome://settings/content/microphone`.
4. Дождитесь статуса «На линии». Теперь вкладку U-POS можно закрыть. Chrome должен оставаться запущенным, а компьютер — подключённым к сети.

Когда расширение владеет линией, телефон на открытых вкладках U-POS уступает ему SIP-регистрацию. Набор номера из сайта передаётся расширению. Если расширение отключено, сайт снова регистрирует свою линию.

Панель расширения включает набор с клавиатурой и настраиваемым звуком клавиш, DTMF во время разговора, выключение микрофона, историю с фильтрами входящих, исходящих и пропущенных, сохранение контакта, открытие карточки клиента, ответ, отклонение и переадресацию. В настройках можно сохранить до десяти быстрых номеров перевода. До ответа отправляется SIP 302, во время разговора — SIP REFER; итоговое переключение зависит от АТС. История и контакты доступны при действующем входе в U-POS в этом профиле Chrome, даже если вкладка сайта закрыта. Вкладки `chrome://` и другие защищённые страницы Chrome не допускают встроенный виджет; для них расширение открывает отдельное окно.

Если U-POS открыта в нескольких вкладках одного браузера, SIP-линию регистрирует только одна вкладка. Остальные ждут освобождения линии и не создают повторный SIP-контакт.

После перезапуска Chrome или обновления расширения откройте U-POS и повторите подключение: SIP-пароль и токен хранятся только в `chrome.storage.session`. При необходимости можно раскрыть ручной ввод SIP-данных. Выделенный на странице номер можно набрать через контекстное меню Chrome.

Записи отправляются в U-POS и далее в настроенную Telegram-группу. Настройки IVR в U-POS включают текст приветствия, кнопки 0–9, очереди и цепочки последующих внутренних или внешних номеров с шагом пять секунд. Их можно прослушать и сохранить как схему, но они не управляют действующим входящим маршрутом, пока UCALL Centre не направит рабочий номер на голосовой узел или не предоставит API управления АТС.
