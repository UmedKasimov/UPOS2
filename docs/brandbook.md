# U-POS FINANCE — брендбук интерфейса

Единый стандарт внешнего вида. Любая новая вёрстка обязана следовать этим
правилам; при доработке старых экранов — приводить их к стандарту.

## 1. Цвет

**Один акцентный цвет — синий.** Зелёные, красные и жёлтые акценты в
интерфейсе не используются.

| Токен / hex | Назначение |
| --- | --- |
| `--primary` `#2563eb` | Акцент: кнопки, ссылки, активные вкладки, выделения |
| `--btn-edge` `#1d4ed8` | Нижняя «грань» 3D-кнопки, нажатые состояния |
| `#1e40af` | Тёмно-синий текст акцентных значений (суммы, статусы) |
| `#dbeafe` / `#eff6ff` | Светло-синие подложки выделений |
| `#334155` / `#475569` | Грифельно-синий: «негативные» значения, опасные действия |
| `#64748b` / `#94a3b8` | Второстепенный текст, нейтральные бейджи |
| `#e2e8f0` / `#f1f5f9` / `#cbd5e1` | Нейтральные подложки |
| `--brand-navy` `#141d2e` | Тёмный бренд-фон (шапки, сайдбар-темы) |

Семантика без светофора: положительное — синий (`#2563eb`/`#1e40af`),
отрицательное — грифельный (`#334155`), нейтральное — серо-синий (`#64748b`).

## 2. Градиенты

**Запрещены полностью** (linear/radial/conic) — фоны, кнопки, текст, бейджи
только плоским цветом.

## 3. Кнопки — фирменный 3D-стиль

Единственный стиль кнопок в программе (класс `.btn`):

- плоская заливка `--primary`, без градиента;
- объём — нижняя грань `box-shadow: 0 3px 0 var(--btn-edge)`;
- нажатие «утапливает»: `translateY(2px)` + грань 1px;
- скругление `--radius` (0.7rem), вес шрифта 600;
- вторичная кнопка `.btn-secondary` — белая с серой гранью, та же механика.

Никаких стеклянных/градиентных/плоско-бестеневых кнопок.

## 4. Шрифт

- Семейство: **Inter** (уже подключено), системный фолбэк.
- Размеры — только из шкалы `--text-xs … --text-2xl` (13/15/16/18/22/26/32).
- Веса: 400 текст, 600 кнопки и подписи, 700 значения, 800 заголовки-цифры.
- Цвет текста — только `--foreground`, `--muted-foreground` и синие из §1.

## 5. Скругления

- Контролы (кнопки, инпуты, селекты): `--radius` (0.7rem).
- Карточки, панели: `--radius-lg` / `--radius-xl`.
- Пилюли и чипы: `999px`.
- Произвольные значения скруглений не вводить.

## 6. Тени

Только три уровня: `--shadow-sm` (контролы), `--shadow-md` (карточки),
`--shadow-lg` (модалки/поповеры) + грань кнопок из §3. Другие тени не вводить.

## 7. Таблицы (эталон — Клиенты/Поставщики)

Сортировка `↕` во всех колонках, перетаскивание колонок, итоговая строка
снизу, нумерация строк CSS-счётчиком, суммы по валютам раздельно.

**Ширина колонок — как в Excel.** Ширина таблицы равна сумме колонок
(`--upos-table-column-total-width`), `table-layout: fixed`. Тянешь границу —
меняется только эта колонка, соседние стоят на месте; не помещается —
горизонтальная прокрутка. Никаких `width: max(100%, …)`: лишнее место
браузер раскидает по соседям и потянутся сразу две колонки.
Базовые ширины снимаются только с видимой таблицы — у скрытой все замеры
нулевые и колонки схлопываются в минимум.

**Настройка столбцов** — кнопка-шестерёнка в заголовке колонки «Действия».
Отдельной служебной колонки быть не должно: она оставляет пустую ячейку в
каждой строке.

**Содержимое ячейки не выходит за колонку**: `overflow: hidden` на `td`,
вложенные элементы `min-width: 0`, селекты и инпуты `width: 100%`.

**Контролы в таблицах одинаковы**: иконки действий, шестерёнка и селекты
статусов — скругление `--radius` и видимая рамка `var(--border)`. Не бывает
«кнопки с линией» и «кнопки без линии».

## 9. Проверка перед коммитом

Тёплых цветов в стилях быть не должно. Проверка: разобрать каждый hex по
цветовому кругу — допустимы только оттенки с тоном 200–280° либо
насыщенностью < 0.12 (нейтрали). Всё остальное — ошибка.

Смешивать цвета только `color-mix(in srgb, …)`. В `oklch` путь от белого к
синему проходит через розовый сектор, и светлые подложки становятся
розовыми.

## 8. Тёмная тема

Все цвета берутся из токенов — тёмная тема (`html.dark`) переопределяет
токены и не требует отдельных правок компонентов.
